# Спортивная мафия — Railway + GitHub

Полная версия школьного турнирного сайта на Python без сторонних библиотек.

## Что внутри
- современный адаптивный минималистичный интерфейс;
- общий рейтинг и статистика;
- страницы игроков с фото и историей игр;
- поиск игроков;
- раунды/игры;
- ролевые номинации;
- «Тактик турнира»;
- панель ведущего;
- добавление/удаление игроков, игр и результатов;
- редактирование названия турнира;
- смена пароля;
- экспорт JSON;
- защита админ-сессии cookie;
- атомарная запись данных;
- совместимость со старым форматом списка игроков;
- фото через папку `images/`.

## Фото
Файлы: `images/1.png`, `images/2.jpg`, `images/3.webp` и т.д.
В админке у игрока укажи `1`, `2`, `3` или полное имя файла.

## Railway
Рекомендуется создать Volume и подключить его к `/data`, затем переменную окружения `DATA_DIR=/data`. Иначе данные в контейнере могут быть потеряны при пересоздании сервиса.

Переменная `PORT` задаётся Railway автоматически.
Пароль по умолчанию: `mafia` — обязательно смени после первого входа.
